# CCNA-Prep-Labs

Hands-on networking labs I completed while studying for the **Cisco CCNA (200-301)**, based on Jeremy's IT Lab's free CCNA course on YouTube.

I won't upload every lab from the course. This repo only contains the ones I found most interesting or learned the most from.

## Labs

| Day | Topic | What it covers |
|-----|-------|----------------|
| 11 | [Troubleshooting Static Routes](./Day%2011%20-%20Troubleshooting%20Static%20Routes) | Finding and fixing misconfigured static routes in a broken network |
| 15 | [VLSM](./Day%2015%20-%20VLSM) | Subnetting an address block with variable-length subnet masks |
| 18 | [Multilayer Switching](./Day%2018%20-%20Multilayer%20Switching) | Modifying an earlier lab with an L3 switch. |
| 22 | [Rapid STP](./Day%2022%20-%20Rapid%20STP) | Configuring and verifying Rapid Spanning Tree Protocol |
| 24 | [Floating Static Routes](./Day%2024%20-%20Floating%20Static%20Routes) | Backup routes using higher administrative distance |

## Tools

- [Cisco Packet Tracer](https://www.netacad.com/courses/packet-tracer) for building and simulating the topologies

## How to use

1. Clone the repo:
   ```bash
   git clone https://github.com/kovacsmark2015/CCNA-Prep-Labs.git
   ```
2. Open the folder for the lab you want.
3. Open the Packet Tracer file (`.pkt`) in Cisco Packet Tracer.
